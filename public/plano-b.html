Como funciona o Plano B

Shopee → catálogo de até 20 produtos → mensagem e imagem → sua revisão → cópia manual para o canal escolhido.

Dados públicos das ofertas vêm da API Shopee consultada pelo GitHub Actions. As credenciais permanecem protegidas no GitHub. Não são coletados contatos nem criados envios.

Etapa futura: configurar um canal Telegram e um servidor para guardar o token do bot. Para WhatsApp, verificar primeiro quais operações são suportadas oficialmente. Nenhum custo de envio é contratado nesta versão; limites e custos dos serviços serão verificados antes de ativar uma integração.

Telegram, WhatsApp e Instagram só poderão receber envios deste módulo após implementação e sua autorização expressa.
